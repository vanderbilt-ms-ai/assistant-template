# Worked examples

Every file in this directory is a filled-in version of the corresponding template,
written for a fictional person. Nobody here is real. The organizations, documents,
and numbers are invented.

Read them before running `/setup`. They exist to show the level of specificity a
finished identity file needs, not to be copied. A rule lifted from Morgan Reyes
into your own file is a rule about a person who does not exist.

The fictional setup, so the examples hang together:

- **Morgan Reyes**, Director of Partnerships at Cedar Commons, a regional housing
  nonprofit. Half the job is funder relationships, grant reporting, and partner
  agreements.
- Serves on the board of the Riverside Youth Collective, a smaller org, chairing
  its finance committee.
- Runs a household with two kids and an aging parent, which generates its own
  steady stream of paperwork and scheduling.
- Assistant is named **Wren**.

Three lanes, three different sets of readers, one head. That is the shape the
template is built around.

These files are not loaded at session start. They cost nothing to keep.
