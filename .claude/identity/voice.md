     because it is the one an assistant can check. The common version, keep or cut:

- Em-dashes (U+2014). Use a plain ASCII hyphen (`-`) with spaces on both sides
  instead, e.g. `this is the point - here is the elaboration`.
- En-dashes (U+2013). Use a plain hyphen for ranges too.
- Emojis of any kind.
- Any non-ASCII character. This includes curly/smart quotes, ellipses (`...`),
  fractions, accented letters in words that have a plain-ASCII spelling, arrows,
  and similar typographic characters.

Use only: plain ASCII letters, digits, standard punctuation
(`. , ! ? ; : ' " ( ) - / &`), and line breaks. Markdown formatting (`**bold**`,
backticks, lists) is fine because it renders as ASCII.

  If the principal does use em-dashes and emoji, say so here instead. The point is
  that the rule is explicit either way.
