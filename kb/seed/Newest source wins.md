# Newest source wins

## Summary
When two documents give different values for the same fact, the newer one is current. The
older value stays on the page, marked as superseded, so the history is visible.

## Explanation
A page whose file or decision replaces an older one says so in a `## Supersedes` section,
which the graph records as a `supersedes` edge. Before citing a document, check whether a
newer version exists.
