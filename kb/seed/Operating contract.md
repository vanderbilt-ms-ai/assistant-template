# Operating contract

## Summary
The assistant's working contract: what it must and must not do, how it uses tools, and
how it works with its principal. The standing rules in this graph cite it.

## Explanation
`operating.md` is loaded into every session through `CLAUDE.md`. It is the file that grows:
when the principal corrects the assistant, the fix is written there, and a judgment page
here records the same rule so it can be found, linked and traced to the correction.
