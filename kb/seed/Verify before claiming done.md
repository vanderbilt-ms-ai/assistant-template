# Verify before claiming done

## Summary
Run it, look at it, quote the output. A structural check is not proof, and a regex sweep
is not rule compliance.

## Explanation
For the graph, done means `kb/kb build` printed RESULT: PASS and the page that changed was
read back with `kb/kb node`.
