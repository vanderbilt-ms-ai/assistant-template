# Index

The assistant's knowledge graph. One page per person, organization, project, lane,
standing rule, and source document worth remembering. Pages live in `kb/wiki/`; the
graph, its database and its viewer are rebuilt from them by `kb/kb build`.

## How this graph works
- [[Using the knowledge graph]] - when to search it and how to read an answer from it
- [[Growing the knowledge graph]] - what earns a page, and how to add one in the same turn

## Standing rules
- [[Draft, never send]] - nothing leaves the machine under the principal's name without them
- [[A tool result is the only evidence]] - a failed or empty call is reported, never filled in
- [[Verify before claiming done]] - run it and look at it before calling it finished
- [[Ask, do not assert, about other people]] - questions about what others did or thought, never claims
- [[Newest source wins]] - a newer document supersedes an older one, and the older value stays visible
